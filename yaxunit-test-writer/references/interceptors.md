# Создание мок-перехватчиков

Мокито работает через механизм расширений 1С (`&Вместо`). Чтобы замокировать метод, в тестовом расширении должен существовать файл-перехватчик с соответствующей функцией `&Вместо`.

## Шаг 1 — проверь, существует ли уже перехватчик

Сначала проверь, есть ли уже в тестовом расширении нужный объект и файл перехватчика для нужного модуля. Где лежат метаданные объекта и файл модуля — раздел «Раскладка файлов» reference формата проекта.

- **Файл модуля существует** → просто добавь новую функцию `&Вместо` в конец файла (если код файла обернут в инструкцию препроцессора — внутрь обертки, см. правила шага 2). Метаданные и регистрацию не трогай.
- **Объект заимствован, файла нужного модуля нет** (например, перехвачен модуль объекта, а нужен модуль менеджера) → создай BSL-файл (шаг 2) и выполни действия для этого состояния из reference формата (шаг 3).
- **Объект не заимствован** → создай перехватчик: BSL-файл (шаг 2), заимствование объекта и регистрация (шаг 3).

## Шаг 2 — BSL-файл перехватчика

**Шаблон для функции:**

```bsl
&Вместо("ИмяМетода")
Функция Мок_ИмяМетода(Парам1, Парам2) Экспорт

	ПараметрыМетода = Мокито.МассивПараметров(Парам1, Парам2);

	ПрерватьВыполнение = Ложь;
	Результат = МокитоПерехват.АнализВызова(ОбъектМодуля, "ИмяМетода", ПараметрыМетода, ПрерватьВыполнение);

	Если НЕ ПрерватьВыполнение Тогда
		Возврат ПродолжитьВызов(Парам1, Парам2);
	Иначе
		Возврат Результат;
	КонецЕсли;

КонецФункции
```

**Шаблон для процедуры:**

```bsl
&Вместо("ИмяПроцедуры")
Процедура Мок_ИмяПроцедуры(Парам1) Экспорт

	ПараметрыМетода = Мокито.МассивПараметров(Парам1);

	ПрерватьВыполнение = Ложь;
	МокитоПерехват.АнализВызова(ОбъектМодуля, "ИмяПроцедуры", ПараметрыМетода, ПрерватьВыполнение);

	Если НЕ ПрерватьВыполнение Тогда
		ПродолжитьВызов(Парам1);
	КонецЕсли;

КонецПроцедуры
```

**Правила:**
- `&Вместо("ИмяМетода")` — имя метода в оригинальном модуле, строка
- Имя функции: `Мок_[ИмяМетода]`
- Параметры — точно как в оригинале (включая `Знач` и значения по умолчанию)
- `Экспорт` — только если оригинальный метод экспортный; обработчики событий объекта (`ПередЗаписью`, `ПриЗаписи` и т.д.) не экспортные — `Экспорт` не нужен
- `ОбъектМодуля` в `АнализВызова` — переменная-ссылка на объект, не строка:
  - Общий модуль: `ИмяМодуля`
  - Менеджер документа: `Документы.ИмяДок`
  - Менеджер справочника: `Справочники.ИмяСпр`
  - Менеджер регистра: `РегистрыСведений.ИмяРС`
  - Модуль объекта документа или справочника: `ЭтотОбъект` (экземпляр, не менеджер)
  - Набор записей регистра сведений: `ЭтотОбъект` (экземпляр набора записей)
- Для **модуля объекта** мок в тесте настраивается на конкретный экземпляр, а не на менеджер:

  ```bsl
  // Менеджер:
  Мокито.Обучение(Документы.ЗаказПокупателя).Когда("МойМетод").Вернуть(42).Прогон();
  // Объект:
  Объект = Документы.ЗаказПокупателя.СоздатьДокумент();
  Мокито.Обучение(Объект).Когда("МойМетод").Вернуть(42).Прогон();
  ```

- `ПродолжитьВызов(...)` — передаёт те же параметры что получили, не добавлять лишних
- **Инструкция препроцессора.** Перехватчику нужна только одна инструкция — та, которой модуль объекта, менеджера или набора записей исключает клиентский контекст (#std680): `#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда ... #КонецЕсли`. Порядок слов в условии может отличаться, важен состав: `Сервер`, `ТолстыйКлиентОбычноеПриложение`, `ВнешнееСоединение`.
  - Метод в оригинальном модуле находится внутри такой инструкции (на любом уровне вложенности) — оберни перехватчик в нее. Несколько перехватчиков одного файла — внутри одной общей обертки.
  - Такой инструкции вокруг метода нет — обертка не нужна.
  - Остальные инструкции оригинала не повторяй, даже если метод находится внутри них (например, `#Если НЕ МобильныйАвтономныйСервер Тогда`). Ветку `#Иначе ВызватьИсключение ...` из модуля объекта тоже не переноси — она уже есть в оригинале.

  ```bsl
  #Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда

  &Вместо("ИмяМетода")
  Функция Мок_ИмяМетода(Парам1) Экспорт
  	// ... тело по шаблону выше
  КонецФункции

  #КонецЕсли
  ```

  Почему: обертка задает только контекст компиляции перехватчика — он должен компилироваться там же, где перехватываемый метод. Структуру кода оригинала воспроизводить не нужно.

**Пример с несколькими методами в одном файле:**

```bsl
&Вместо("ЭтоКолеровка")
Функция Мок_ЭтоКолеровка(Знач Услуга) Экспорт

	ПараметрыМетода = Мокито.МассивПараметров(Услуга);

	ПрерватьВыполнение = Ложь;
	Результат = МокитоПерехват.АнализВызова(КолеровкаПовтИсп, "ЭтоКолеровка", ПараметрыМетода, ПрерватьВыполнение);

	Если НЕ ПрерватьВыполнение Тогда
		Возврат ПродолжитьВызов(Услуга);
	Иначе
		Возврат Результат;
	КонецЕсли;

КонецФункции

&Вместо("ПолучитьУслугиКолеровки")
Функция Мок_ПолучитьУслугиКолеровки() Экспорт

	ПараметрыМетода = Мокито.МассивПараметров();

	ПрерватьВыполнение = Ложь;
	Результат = МокитоПерехват.АнализВызова(КолеровкаПовтИсп, "ПолучитьУслугиКолеровки", ПараметрыМетода, ПрерватьВыполнение);

	Если НЕ ПрерватьВыполнение Тогда
		Возврат ПродолжитьВызов();
	Иначе
		Возврат Результат;
	КонецЕсли;

КонецФункции
```

## Шаг 3 — метаданные и регистрация (только при создании нового файла модуля)

Перехватчик — это **adopted**-расширение существующего объекта основной конфигурации. Как заимствовать объект или дополнить уже заимствованный и как зарегистрировать его в расширении — разделы «Заимствование объекта для перехватчика» и «Регистрация» reference формата проекта.
